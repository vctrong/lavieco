Bảng Quy Chuẩn Kiểm Tra Thiết Kế (Design Audit & Rationale)

✓
Khoảng thở liên kết (~32px): Các mục điều hướng không còn dính sát icon người dùng hay mép logo; độ rộng chữ ổn định trên 1 dòng duy nhất.
✓
Active State tinh xảo: Chỉ sử dụng duy nhất một chấm vàng kim Canary (#E7DD6A) ngay dưới chân chữ tab được chọn, không đổi màu chữ gây rối mắt.
✓
Triệt tiêu Hamburger Desktop: Thanh Desktop trở về dạng chuẩn Gallery tối giản; các mục phụ dồn vào cụm Khám phá ▾ có card mô tả giàu thông tin.
✓
3 Trạng thái tài khoản phân cấp rõ: Khách (Guest với nút đăng nhập thanh lịch) → Học viên đã đăng nhập (Avatar 32px viền Emerald kèm menu vé) → Quản trị viên (Huy hiệu Admin & Portal quản lý xưởng).
✓
Thích ứng mượt mà khi cuộn (Scrolled 52px): Tự động hạ chiều cao, kích hoạt lớp phủ kính mờ 85% và viền Mint Mist mỏng giữ vững tầm nhìn khi lướt web.
✓
Tablet 1024px & Mobile 390px chuẩn mực: Tablet dồn 2 mục vào "Thêm ▾"; Mobile sở hữu drawer trượt toàn màn hình mang tính thẩm mỹ cao như sách nghệ thuật.
